# 04 · 网格卡片 (Grid / Card)

内容切成矩形卡片, 网格排列, 每卡片一个模块或一条目。视觉上像作品集/仪表盘。

## 结构

```
┌─────────────────────────────────────┐
│  张三 · 全栈工程师 · 联系方式一行       │
├──────────┬──────────┬───────────────┤
│ ┌──────┐ │ ┌──────┐ │ ┌──────┐      │
│ │技能卡 │ │ │语言卡 │ │ │证书卡 │      │
│ └──────┘ │ └──────┘ │ └──────┘      │
│ ┌─────────────┐    ┌──────────────┐ │
│ │ 项目卡 1     │    │ 项目卡 2      │ │
│ └─────────────┘    └──────────────┘ │
└─────────────────────────────────────┘
```

## 字段容量

低。卡片适合短内容 (技能/证书/标签), 长文本 (工作描述/业绩列表) 塞卡片里会被切得很碎。

## 优点 / 缺点

- ✅ 视觉冲击强, 适合设计师/前端展示作品
- ✅ 碎片字段 (技能/语言/证书) 展示效果好
- ❌ **解析最差**: 网格的二维布局转一维文本流完全无序
- ❌ 长文本字段无处安放, 工作经历这种主线模块被迫降级
- ❌ 打印最不友好: 卡片跨页断裂是常态
- ❌ 实现最贵: 网格对齐、不等高卡片处理、响应式断点全要单独调

## 平台解析兼容性: ❌ 差

不推荐用于投递版。只适合做线上展示版/portfolio。

## 代表模板

- 各类 portfolio 主题 (HTML5 UP 等); 中文简历圈此风格少见, 多见国外 creative resume

## 对 CV 项目的适配要点

- 跟项目「平台解析优先」定位正面冲突, **仅收录备查**
- 若用户未来要「线上展示页」: 可以 skills/certificate 两个 section 局部用卡片 (skills 现在已是 skills-grid), 主体仍单栏 — 即「单栏 + 局部卡片」混合, 而不是整页网格
