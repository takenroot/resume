# 01 · 单栏时间序 (Single Column / ATS 标准版式)

最主流、解析最稳的版式。所有内容从上到下一条线, 按模块顺序排列。

## 结构

```
┌─────────────────────────────────────┐
│  [头部: 姓名 / 联系 / 期望, 见下方变体]      │
├─────────────────────────────────────┤
│  工作经历                             │
│    公司 · 职位              时间       │
│    描述 / 业绩 / 标签                  │
├─────────────────────────────────────┤
│  项目经验 (同构)                      │
├─────────────────────────────────────┤
│  教育背景 (同构)                      │
├─────────────────────────────────────┤
│  专业技能 / 语言 / 证书 / 自我评价       │
└─────────────────────────────────────┘
```

模块内部统一样式: 标题行 (左名称右时间) + 正文 + 列表。条目按时间倒序。

## 字段容量

中。纵向空间换内容量, 一页 A4 约 4-6 个模块、每模块 2-3 条。字段多靠**显隐开关**控制, 不靠布局硬塞。

## 优点 / 缺点

- ✅ 阅读顺序 = 文档顺序, 招聘平台解析零歧义; OCR 友好
- ✅ 打印分页行为可预期 (模块整体拆页)
- ✅ 实现最简单, CSS 一列到底
- ❌ 纵向费纸, 内容多易超一页
- ❌ 右侧空间利用率低 (时间列后大片空白)

## 平台解析兼容性: ✅ 最佳

单栏从上到下是唯一所有解析器 (Boss/智联/猎聘 + 国外 ATS) 都假设的阅读顺序。

## 头部变体 (本版式可挂 4 种头部)

### H1 左信息右头像 — CV 现状

```
┌──────────────────────────┬────────┐
│ 📞 电话    ✉️ 邮箱        │        │
│ 📍 所在地  💼 求职状态     │  头像   │
│ 🔗 GitHub  💬 微信        │        │
│ [期望职位] [期望薪资] [城市] │        │
└──────────────────────────┴────────┘
```
icon+text 两列网格。字段少时整齐; **字段一多网格错位 + 头像压缩信息宽度 → 乱**。2026-08 遇到的痛点就是这个。

### H2 无头像三层收束 — billryan 式 (推荐)

```
┌─────────────────────────────────────┐
│  张三                          [头像?] │
│  全栈开发工程师                        │
│  138-0000 · a@b.com · 北京 · 随时到岗  │
│  [期望: 全栈开发] [15-20K] [北京/上海]  │
└─────────────────────────────────────┘
```
- 第 1 层: 姓名最大 + 岗位次之 (可有头像, 缩小贴右)
- 第 2 层: 关键联系信息一行, `·` 分隔, **无 icon** (icon 在密度高时是噪点)
- 第 3 层: 期望类走标签胶囊 (= CV 现在的 header-extra)
- 容量 ~10 条仍不乱, 因为三层权重分明

### H3 居中极简 — crispgm 式

```
│            张  三                   │
│        全栈开发工程师                │
│   电话 · 邮箱 · 所在地 · GitHub      │
```
最干净, 容量最小 (~6 条), 适合字段本来就少的人。

### H4 侧栏收纳

头部只剩姓名+岗位, 联系方式全进侧栏 → 见 [02-sidebar.md](02-sidebar.md)。

## 代表模板

- [billryan/resume](https://github.com/billryan/resume) / [hijiangtao/resume](https://github.com/hijiangtao/resume) — H2 的 LaTeX 经典实现
- [crispgm/resume](https://github.com/crispgm/resume) — H3, Jekyll 极简
- [geekcompany/ResumeSample](https://github.com/geekcompany/ResumeSample) — 中文程序员单栏共识
- [xitanggg/open-resume](https://github.com/xitanggg/open-resume) — 国外 ATS 导向 builder, 单栏, 内置解析测试

## 对 CV 项目的适配要点

- 现状即此版式, 要改的只是**头部 H1 → H2**: 去 icon 用 `·` 分隔、头像可选化、期望标签行保留
- `fields.json` 所有 profile 字段在 H2 里都有位置: 第 2 层放联系类, 第 3 层放期望类, 其余 (firstWorkDate/gender/birthDate 等) 默认不渲染 — 正好接上「字段显隐」需求
- section 渲染逻辑 (renderItem) 零改动
