# 03 · 上下分栏 (Split Columns / LaTeX 双栏)

单栏头部 + 两栏主体: 名字联系方式占满顶部整行, 下面内容分左右两列 (通常左窄右宽或均分)。

## 结构

```
┌─────────────────────────────────────┐
│  张三 · 全栈工程师                     │
│  电话 · 邮箱 · 所在地                  │  ← 头部整行单栏
├──────────────────┬──────────────────┤
│ 技能             │ 工作经历            │
│ 语言             │                   │
│ 证书             │ 项目经验            │
│ 教育             │                   │
└──────────────────┴──────────────────┘
```

跟 02 侧栏的区别: 头部是整行的 (姓名不吃栏宽), 分栏只作用于主体; 侧栏版式连头部都劈开。

## 字段容量

高, 跟 02 相当。

## 优点 / 缺点

- ✅ 头部阅读顺序无歧义 (比 02 好), 解析器至少能稳稳拿到姓名/电话
- ✅ 主体密度高, 适合内容多的应届生 (教育/实习/项目/获奖全塞下)
- ❌ 主体两栏仍有阅读顺序歧义
- ❌ 两栏内容长度不平衡时底部留白难看
- ❌ 打印分页同样难

## 平台解析兼容性: ⚠️ 有风险

比 02 略好 (头部保住了), 主体仍会串行。

## 代表模板

- [dyweb/Deedy-Resume-for-Chinese](https://github.com/dyweb/Deedy-Resume-for-Chinese) — Deedy 中文版, 此版式最经典实现, 应届生圈流行
- [resume-ng](https://github.com/fky2015/resume-ng) — 主打「信息密度 × 美学」的 LaTeX 模板

## 对 CV 项目的适配要点

- 适配方式同 02: `column` 声明 + renderer 分桶
- 跟 H2 头部天然兼容 (头部本来就整行)
- **同样不建议现阶段做**, 收录是为了未来若出「密度版」形态时有据可查
