# 05 · 时间轴主线 (Timeline)

页面中央或左侧一条竖线, 经历/教育作为节点挂在线上, 强调时间叙事。

## 结构

```
┌─────────────────────────────────────┐
│  头部 (任意变体)                      │
├─────────────────────────────────────┤
│ 2026 ●━━━ 乾岳驭空 · 运维工程师        │
│      ┃    描述/业绩...                │
│ 2020 ●━━━ 杭州中奥 · 数据处理          │
│      ┃    描述/业绩...                │
│ 2019 ●━━━ 河套学院 · 本科             │
│      ┃                               │
├─────────────────────────────────────┤
│  技能 / 语言 (正常模块)                │
└─────────────────────────────────────┘
```

## 字段容量

低。时间轴节点留给内容的宽度窄 (线+时间标签吃掉左侧), 长业绩列表会拖得很长。

## 优点 / 缺点

- ✅ 时间叙事直观, 适合职业路径有故事性的人 (转行/晋升线)
- ✅ 视觉辨识度强
- ❌ 时间标签跟内容分离, 解析器可能把时间跟错误的公司配对
- ❌ 不同模块混排一根线时, 「模块」概念消失, 平台按模块归类的解析逻辑失效
- ❌ 空窗期/重叠期难看

## 平台解析兼容性: ⚠️ 有风险

比双栏好一点 (仍是单栏从上到下), 但时间-公司-职位的空间绑定关系被打散。

## 代表模板

- CV 项目自身有 `timeline` section 类型 (条目级时间轴, 非整页版式)
- 国外视觉系简历常见; 中文技术简历圈基本不用整页时间轴

## 对 CV 项目的适配要点

- CV 已有 `timeline` section type, 「条目级时间轴」已经能做 — 整页版式必要性低
- 若未来做: renderer 加一个 timeline 容器变体, 把 experience+education 按 period 排序混排; 但 `sortPeriod` 解析依赖 period 格式, 空 period 条目要兜底
- **仅收录备查**, 不建议做整页版式; 保留现有条目级 timeline section 即可
