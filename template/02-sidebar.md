# 02 · 双栏侧栏 (Sidebar)

左窄右宽: 窄栏放个人信息/技能/语言/证书, 宽栏放经历/项目/教育主线。

## 结构

```
┌────────────┬────────────────────────┐
│ 头像        │ 姓名                    │
│            │ 岗位                    │
│────────────│                        │
│ 联系方式    │ 工作经历 (主线, 倒序)     │
│  电话       │                        │
│  邮箱       │────────────────────────│
│  所在地     │ 项目经验                │
│────────────│                        │
│ 技能        │────────────────────────│
│  (进度条?)  │ 教育背景                │
│────────────│                        │
│ 语言/证书   │                        │
└────────────┴────────────────────────┘
```

## 字段容量

高。侧栏是「碎片字段收纳区」: 技能、语言、证书、联系方式这些短字段各给一块, 不占主线纵向空间。字段多的人最受益。

## 优点 / 缺点

- ✅ 空间利用率高, 信息密度大
- ✅ 技能/语言这类碎片字段有专属位置, 天然分组
- ❌ **阅读顺序歧义**: 人眼是 Z 字形还是先看侧栏? 解析器更不知道 — 先读哪栏没有标准答案
- ❌ 打印分页难看: 侧栏跨页断裂难处理, A4 第二页侧栏留白
- ❌ 实现成本高: 两列宽度配比、移动端要塌缩成单栏

## 平台解析兼容性: ⚠️ 有风险

解析器按 DOM/坐标顺序读文本流, 双栏会把「电话邮箱」跟「工作经历」交叉混在一起, 字段识别率下降。**用此版式必须实测 Boss/智联解析再上线。** 国外 ATS 指南一律劝退双栏。

## 代表模板

- [xriley/Orbit-Theme](https://github.com/xriley/Orbit-Theme) — Bootstrap 侧栏式开发者简历, 此版式最流行实现
- [Horldsence/resume_template](https://github.com/Horldsence/resume_template) — 中文双栏 LaTeX

## 对 CV 项目的适配要点

- 若未来要做: SECTION_CONFIG 加 `column: 'side' | 'main'` 声明, renderer 按列分桶渲染; skills/language/certificate/profile 归侧栏
- 打印样式要单独设计: @media print 时侧栏塌成顶部横带 or 保持双栏, 需实测
- 跟「字段显隐」需求兼容: 侧栏碎片字段多, 更显隐友好
- **不建议现阶段做** — 跟 OCR/解析优先的项目定位冲突, 除非用户明确要「展示版」形态
